# Shoe Store Database Management System

A web-based database management application developed for CSE 3330 (Databases and File Structures) at the University of Texas at Arlington.

## Overview

This project provides a web interface for interacting with a PostgreSQL shoe store database. Users can retrieve employee information and perform customer management operations.

## Tech Stack

- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **Database Driver:** psycopg
- **Frontend:** HTML
- **Development Tools:** pgAdmin 4, Git

## Features

Planned functionality includes:

- Search for employees hired on or after a specified date.
- Insert new customer records.
- Update customer email addresses.
- Delete customer records.
- Retrieve sales information using SQL views.
- Generate sales summaries using SQL queries.

## Project Structure

The application will use Flask for handling HTTP requests, PostgreSQL for data storage, and HTML templates for displaying results.
